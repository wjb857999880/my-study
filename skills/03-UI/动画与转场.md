# 动画与转场

## 概述
Android 动画体系:**补间动画**(View Animation,只改绘制不改实际位置,局限大)、**属性动画**(Property Animator,`ValueAnimator` / `ObjectAnimator`,真正改属性,主力方案)、**转场动画**(Activity / Fragment 共享元素过渡、Transition)、**物理动画**(SpringAnimation、Fling)。Compose 有 `animate*AsState` / `AnimatedContent` / `Animatable` 等。关键:硬件层加速(改 translation / alpha / scale 不触发 layout)、避免每帧 requestLayout、按帧预算(16.6ms)。动画是体验打磨的核心。

## 核心原理 / 关键点

### 1. Android 动画四大体系
- **补间动画(View Animation)**:只改绘制、不改 View 实际属性 / 位置(alpha / scale / translate / rotate),点击区域不动,局限大。
- **属性动画(Property Animator)**:真正修改对象属性,主力方案。
- **转场动画(Transition)**:Activity / Fragment 进入退出过渡、共享元素。
- **物理动画**:基于 Spring / Fling 的力学动画,自然顺滑。

### 2. 属性动画原理
`ValueAnimator` 算值:由**插值器(Interpolator)** 决定时间→进度曲线(加速 / 回弹 / 减速),**估值器(TypeEvaluator)** 决定进度→具体值;`ObjectAnimator` 再把值反射 set 回目标属性。属性动画因此真正改变 View 状态。

### 3. ViewPropertyAnimator
`view.animate().translationY(100f).setDuration(200).start()` 一行式,对常见属性(translation / alpha / scale / rotation)做组合动画,比 ObjectAnimator 简洁,适合简单交互反馈。

### 4. 转场与共享元素
Activity / Fragment Transition(explode / fade / slide)与**共享元素过渡(shared element)**:列表 → 详情的图片无缝放大。配置 window activity transitions、给共享 View 设 `transitionName`。

### 5. 物理动画(SpringAnimation / FlingAnimation)
基于 `DynamicAnimation`(androidx.dynamicanimation),用刚度 / 阻尼描述,终点自然减速甚至回弹,比固定曲线更真实(拖拽回弹、列表侧滑、惯性滚动)。

### 6. Compose 动画
声明式 API:`animate*AsState`(状态间过渡)、`AnimatedContent`(内容切换)、`Animatable`(精细控制)、`updateTransition`(多属性一起过渡)。用 `AnimationSpec`(tween / spring / keyframes)定制曲线。

### 7. 性能:硬件层与避免 layout
- 改 `translationX/Y`、`alpha`、`scaleX/Y`、`rotation` 不触发 layout,只走合成层(硬件加速),性能好。
- 改 `width / height / margin / padding` 触发 measure / layout,**每帧重算易卡**。
- 每帧预算约 16.6ms(60Hz),超时掉帧;可 `setLayerType` 开硬件层、用 Choreographer 监控。
- 开启 GPU 过度绘制检查,减少 Overdraw。

### 8. 动画与无障碍 / 减少动效
尊重系统「减少动态效果」设置(`ANIMATOR_DURATION_SCALE`),为前庭敏感用户降级或关闭动画;动画不应成为信息传达的唯一手段。

## 实践经验 / 踩坑

1. **补间动画位置不变**:用补间移动后,View 实际位置(点击区)仍在原处;要真实位移用属性动画。
2. **动画里改布局属性**:width / margin 触发 requestLayout,每帧 measure / layout → 卡顿;改 translation / alpha / scale。
3. **ObjectAnimator 需 setter**:目标属性必须有公开 setter;字段无 setter 动不了(用 ValueAnimator 手动 set)。
4. **动画未取消致泄漏**:Activity 销毁未 cancel 的 Animator 持 View;用生命周期停止,Compose 动画随组合自动管理。
5. **掉帧定位**:Perfetto 看每帧,锁定 measure / layout / 绘制瓶颈(见 [[卡顿与流畅度优化]])。

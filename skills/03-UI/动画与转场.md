# 动画与转场

## 概述
Android 动画体系:**补间动画**(View Animation,只改绘制不改实际位置,局限大)、**属性动画**(Property Animator,`ValueAnimator` / `ObjectAnimator`,真正改属性,主力方案)、**转场动画**(Activity / Fragment 共享元素过渡、Transition)、**物理动画**(SpringAnimation、Fling)。Compose 有 `animate*AsState` / `AnimatedContent` / `Animatable` 等。关键:硬件层加速(改 translation / alpha / scale 不触发 layout)、避免每帧 requestLayout、按帧预算(16.6ms)。动画是体验打磨的核心。

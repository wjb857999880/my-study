# RecyclerView 自定义组件(ItemDecoration / ItemAnimator / LayoutManager)

## 概述
RecyclerView 的可插拔设计体现在三大扩展点:**`ItemDecoration`**(画间距 / 分割线 / 吸顶)、**`ItemAnimator`**(增删移动 / 变更动画)、**`LayoutManager`**(决定怎么排布与滚动)。本篇讲各自的关键回调、典型场景与最小代码骨架,是脱离内置三件套做定制列表的入口。

## 核心原理 / 关键点

### 1. ItemDecoration:间距与绘制装饰

| 回调 | 作用 | 时机 |
|---|---|---|
| `getItemOffsets(outRect, view, parent, state)` | 给每个 item 设四向 inset | 影响测量/布局,留出分割线/间距空间 |
| `onDraw(canvas, parent, state)` | 在 item **绘制之前**画 | 分割线等,画在 item **后面** |
| `onDrawOver(canvas, parent, state)` | 在 item **绘制之后**画 | 吸顶 header、徽标等,盖在 item **上面** |

- 内置 `DividerItemDecoration`(横向/纵向分割线)。
- `onDraw` / `onDrawOver` 里用 `parent.getChildCount()` 遍历当前可见 child、`parent.getChildAdapterPosition(child)` 拿位置。

**间距装饰示例(每 item 底部留间距):**

```kotlin
class SpaceItemDecoration(private val spacePx: Int) : RecyclerView.ItemDecoration() {
    override fun getItemOffsets(
        outRect: Rect, view: View, parent: RecyclerView, state: RecyclerView.State
    ) {
        outRect.bottom = spacePx
    }
}
// 用:recyclerView.addItemDecoration(SpaceItemDecoration(dp(8)))
```

**吸顶 header(`onDrawOver`)思路:** 找到第一个可见 item 的 position → 按 position 算出该位置的 header 文本/分组 → 在 canvas 顶部画一条 header 条;滚动时持续重绘即实现「粘住顶部」。

### 2. ItemAnimator:增删移动 / 变更动画

- 默认实现 `DefaultItemAnimator`(淡入淡出 + 平移)。基类一般是 `SimpleItemAnimator`。
- **触发链**:`notifyItemXxx` → RecyclerView 记录 **pre / post layout 信息**(`ItemHolderInfo`:left/top/scale/alpha 等)→ 对每个变化回调动画方法 → 动画结束必须 `dispatchAnimationFinished`。
- **旧(常用)API**:`animateAdd` / `animateRemove` / `animateMove` / `animateChange`(返回 `true` 表示自行处理)。

> 注意:**`notifyDataSetChanged()` 不触发动画**(全量刷新、无差分);只有 `notifyItemXxx` 或 DiffUtil 的精准更新才有动画。这也是 [[RecyclerView 四级缓存]] §7 推崇 DiffUtil 的原因之一。

**缩放进入 + 淡出动画示例:**

```kotlin
class ScaleInAnimator : DefaultItemAnimator() {
    override fun animateAdd(holder: RecyclerView.ViewHolder): Boolean {
        holder.itemView.alpha = 0f
        holder.itemView.scaleX = 0.6f
        holder.itemView.scaleY = 0.6f
        holder.itemView.animate().alpha(1f).scaleX(1f).scaleY(1f)
            .setDuration(220).withEndAction { dispatchAddFinished(holder) }.start()
        dispatchAddStarting(holder)
        return true                      // true = 我们自己处理动画
    }
    override fun endAnimation(item: RecyclerView.ViewHolder) {
        item.itemView.animate().cancel() // 复用前必须收尾,否则状态残留
    }
}
// 用:recyclerView.itemAnimator = ScaleInAnimator()
```

### 3. LayoutManager:排布与滚动

内置:`LinearLayoutManager`(线性)、`GridLayoutManager`(网格)、`StaggeredGridLayoutManager`(瀑布流)。自定义需继承 `RecyclerView.LayoutManager`,核心实现:

| 方法 | 职责 |
|---|---|
| `generateDefaultLayoutParams()` | 返回子 view 默认 LayoutParams |
| `onLayoutChildren(recycler, state)` | **核心**:从 recycler 取 view、`addView`、`measure` + `layout` |
| `canScrollVertically()` / `canScrollHorizontally()` | 是否可滚动 |
| `scrollVerticallyBy(dy, recycler, state)` | 滚动:回收滑出的、填充滑入的 |
| `collectAdjacentPrefetchPositions(...)` | 预取位置预测(配合 GapWorker,见 [[RecyclerView 预取源码(GapWorker)]]) |

**最小(不可滚动)纵向骨架——演示「取/造 + 铺」循环:**

```kotlin
class SimpleVerticalLayout : RecyclerView.LayoutManager() {
    override fun generateDefaultLayoutParams(): RecyclerView.LayoutParams =
        RecyclerView.LayoutParams(WRAP_CONTENT, WRAP_CONTENT)

    override fun onLayoutChildren(recycler: RecyclerView.Recycler, state: RecyclerView.State) {
        detachAndScrapAttachedViews(recycler)          // 现有 view 暂存进 scrap
        var y = 0
        for (i in 0 until state.itemCount) {
            val v = recycler.getViewForPosition(i)     // 走四级缓存取/造(见源码解析篇)
            addView(v)
            measureChildWithMargins(v, 0, 0)
            val h = getDecoratedMeasuredHeight(v)
            layoutDecoratedWithMargins(v, 0, y, width, y + h)
            y += h
            if (y > height) break                      // 只铺到可见区
        }
        // 真正可滚动还需实现 scrollVerticallyBy:平移 + recycle 滑出 + fill 滑入
    }
}
```

> 自定义 LayoutManager 最实际的学习路径:**读 `LinearLayoutManager` 源码**的 `fill()` / `recycleBy()` —— 它把「填充 + 回收」的成对操作写成了可复用的模板。

### 4. 选型对照

| 需求 | 用哪个扩展点 |
|---|---|
| 分割线 / 间距 / 吸顶 / 时间轴 | `ItemDecoration` |
| 增删 / 移动 / 变更动画 | `ItemAnimator`(配合 `notifyItemXxx` / DiffUtil) |
| 非标准布局:轮播 / 流式标签 / 环形 / 吸顶网格 | 自定义 `LayoutManager` |

## 实践经验 / 踩坑

1. **ItemDecoration `getItemOffsets` 漏某一向** —— `outRect` 默认全 0;只设了 `bottom` 就只有底间距,别漏。
2. **ItemAnimator 动画结束不 `dispatchAnimationFinished`** —— holder 状态不释放,后续复用错乱/动画堆积;`withEndAction` 里务必调用。
3. **自定义 LayoutManager 回收与填充不成对** —— 只 `addView` 不回收滑出的 → 内存泄漏、view 堆积;`scrollXxxBy` 里 `recycle` 与 `fill` 必须配对(参考 LinearLayoutManager)。
4. **`notifyDataSetChanged` 期望有动画** —— 全量刷新跳过 ItemAnimator;改用 DiffUtil / `notifyItemXxx`。
5. **自定义 LayoutManager 预取不生效** —— 没实现 `collectAdjacentPrefetchPositions`,GapWorker 无预取位置(见 [[RecyclerView 预取源码(GapWorker)]] §5)。
6. **ItemDecoration 里画了却不留 offset** —— 在 `onDraw` 画分割线但 `getItemOffsets` 没留空间,线被 item 盖住。

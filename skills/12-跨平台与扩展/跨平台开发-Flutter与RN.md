# 跨平台开发(Flutter/RN)

## 概述
另两类主流跨平台方案:**Flutter**(Google,Dart,自绘引擎,一套代码多端 UI 高度一致、性能接近原生)、**React Native**(Meta,JS / TS,桥接原生组件,生态大、可复用前端技能)。定位:一套代码多端发布,降低多端团队成本;代价是包体积增大、部分原生能力需桥接、性能 / 体验与原生有差距。高级 Android 了解其原理与取舍即可,看岗位方向决定深度。

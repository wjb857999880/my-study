# 音视频开发

## 概述
音视频是 specialized 方向:**采集 → 编码 → 传输 → 解码 → 渲染** 全链路。核心概念:容器格式(MP4 / FLV)、编解码(H.264 / H.265 / AAC)、**MediaCodec**(硬件编解码 API)、**ExoPlayer / Media3**(Google 播放器)、直播(RTMP / HLS / WebRTC)、OpenGL / 滤镜渲染。直播 / 短视频 / IM 语音赛道需求大。门槛高(信号处理 + C/C++ + Android 多媒体 API),按目标赛道决定是否深入。

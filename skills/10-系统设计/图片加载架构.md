# 图片加载架构

## 概述
图片框架(Glide / Coil)的核心:**三级缓存**(内存 LRU → 磁盘 → 网络)+ 异步解码 + 采样压缩(inSampleSize)+ 生命周期绑定 + Bitmap 复用。设计点:内存上限与淘汰、解码线程池、占位 / 圆角 / 转换、列表复用防错位与闪烁。

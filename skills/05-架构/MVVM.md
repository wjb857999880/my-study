# MVVM

## 概述
Model-View-ViewModel：View 订阅 ViewModel 暴露的可观察状态，ViewModel 持有业务逻辑与状态，解耦界面与逻辑。

## 自评依据  ★必填
多个项目主力架构都用 MVVM + ViewModel + LiveData/Flow，能独立设计分层与数据流，
也能给别人讲清；已达"掌握"，目标维持。

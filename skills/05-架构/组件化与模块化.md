# 组件化与模块化

## 概述
把大型 App 拆成可**独立开发 / 编译 / 测试**的模块(业务组件 + 基础组件 + 壳工程),目标是降耦合、提速构建、支持团队并行。核心问题:**组件间通信与页面跳转**(ARouter / WMRouter 路由、接口下沉、SPI)、依赖方向、公共能力下沉、组件单独调试与集成打包、多模块下的 Gradle 配置(`api`/`implementation`、变体)。

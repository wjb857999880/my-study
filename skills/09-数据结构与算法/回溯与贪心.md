# 回溯与贪心

## 概述
**回溯** = DFS + 撤销选择,求**所有解**(全排列 / 组合 / 子集 / N 皇后),靠剪枝优化。**贪心**每步取局部最优,需能证明全局最优(区间调度 / 跳跃游戏)。判断:求全部解用回溯,求最优且可证明用贪心。

# 回溯与贪心

## 概述
**回溯** = DFS + 撤销选择,求**所有解**(全排列 / 组合 / 子集 / N 皇后),靠剪枝优化。**贪心**每步取局部最优,需能证明全局最优(区间调度 / 跳跃游戏)。判断:求全部解用回溯,求最优且可证明用贪心。

## 核心原理 / 关键点

### 1. 回溯 = DFS + 撤销选择

- 回溯本质是**带撤销的 DFS**:在搜索树上做选择 → 递归 → 撤销选择,回到上一步试别的。
- 求的是**所有解 / 可行解**(排列、组合、子集、棋盘)。
- 模板:路径 + 选择列表 → 做选择 → `backtrack` → 撤销选择。

### 2. 全排列 / 组合 / 子集

- **全排列**:顺序选,用 used 数组去重。
- **组合**:靠 start 控制起始避免重复顺序(组合不分先后)。
- **子集**:每元素选 / 不选,或 start 枚举。
- 含重复元素去重:**先排序 + 同层跳过相同值**(剪枝去重)。

### 3. 剪枝

- 提前判断某些分支不可能产生解,**直接剪掉**不递归,大幅减少搜索。
- 例:组合总和超 target 不再深入;N 皇后同列 / 对角线冲突不放。
- 剪枝是回溯效率的关键,面试常考。

### 4. N 皇后 / 棋盘问题

- 经典回溯:逐行放皇后,检查列 / 对角线冲突,冲突则剪枝。
- 用集合记录已占列 / 对角线,O(1) 判冲突。

### 5. 贪心的本质

- 每一步选**当前看似最优**的选择,期望得到全局最优。
- 适用前提:**贪心选择性**(局部最优能推出全局最优),且**可证明**。
- 不适合所有最优化问题(反例多),用前要先想清为什么贪心是对的。

### 6. 经典贪心

- **区间调度 / 不重叠区间**:按**结束时间**排序,贪心选最早结束。
- **跳跃游戏 / 分发糖果**:局部策略。
- **Huffman 编码 / Dijkstra / 最小生成树**:都是贪心。
- 关键是**正确的排序 / 策略**。

### 7. 回溯 vs 贪心 vs DP 选型

- 求所有解 / 具体方案 → **回溯**(指数级,靠剪枝)。
- 求最优解、子问题重叠、无后效性 → **DP**。
- 求最优解、可证明局部最优 = 全局最优 → **贪心**(通常最快)。
- 模糊时:贪心想不出证明 → 退回 DP;求方案 → 回溯。

### 8. 复杂度与优化

- 回溯最坏指数级 O(2ⁿ) / O(n!),靠剪枝 + 对称性破缺降常数。
- 贪心多为 O(nlogn)(排序)+ O(n)。
- 记忆化:回溯 + 记忆化 → 记忆化搜索(常等价于 DP)。

## 实践经验 / 踩坑

1. **回溯忘撤销选择** —— 状态没还原 → 后续分支错;做选择后必撤销。
2. **组合 / 排列去重错** —— 含重复元素没先排序 + 同层跳过,产生重复解。
3. **没剪枝导致超时** —— 明显不可能的分支还深递;加提前判断。
4. **贪心滥用** —— 没证明就贪,遇到反例错;不确定先 DP。
5. **贪心排序依据错** —— 按起点的贪心常错,区间问题多按结束时间。
6. **回溯 path 用同一引用** —— 收集结果时要拷贝,否则后续撤销会改它。
7. **混淆组合与排列** —— 组合不分顺序用 start;排列用 used。

# 栈与队列

## 概述
栈(LIFO)与队列(FIFO)是受限线性结构。进阶:**单调栈 / 单调队列**解决「下一个更大元素」「滑动窗口最值」;栈可模拟递归、做表达式求值 / 括号匹配;队列支撑 BFS 与层序遍历。

## 核心原理 / 关键点

### 1. 栈与队列的基本性质

- **栈 LIFO**(后进先出):入栈 push / 出栈 pop 都在栈顶,O(1)。
- **队列 FIFO**(先进先出):入队尾、出队头,O(1)。
- 都是「受限线性结构」,用数组或链表实现。

### 2. 栈的典型应用

- **括号匹配**:遇左括号入栈,遇右括号弹栈比对。
- **表达式求值**:中缀转后缀(调度场算法)/ 后缀求值用栈。
- **模拟递归 / 撤销(undo)/ 浏览器前进后退**:双栈。
- **函数调用栈**:递归过深 → 栈溢出。

### 3. 单调栈

- 维护一个**单调**的栈,解决「每个元素下一个 / 上一个更大 / 更小元素」。
- 经典:**每日温度**(下一个更暖)、**柱状图最大矩形**(两侧更矮)。
- O(n):每个元素最多入栈出栈一次。

### 4. 单调队列

- 维护一个**单调**双端队列,解决「滑动窗口最值」。
- 经典:**滑动窗口最大值**:队首始终是当前窗口最大。
- 入队时从队尾弹出破坏单调的元素;出队时检查队首是否滑出窗口。

### 5. 队列的典型应用

- **BFS**:层序遍历 / 最短步数(见图)。
- **层序遍历树**:队列逐层处理。
- **双端队列(deque)**:两端都可进出,更灵活。

### 6. 用栈实现队列 / 用队列实现栈

- **两栈实现队列**:一个入栈、一个出栈,出队时若出栈空则把入栈全倒过去(均摊 O(1))。
- 思想:用栈的中转改变访问顺序。面试经典,考对结构本质的理解。

### 7. 最小 / 最大栈

- **最小栈**:支持 O(1) 取最小值;用辅助栈同步记录每个状态的最小值。
- 思路:空间换时间,主栈 + 辅助栈。

### 8. 实现与复杂度

- 数组实现栈:动态扩容;链表实现:天然无容量限制。
- **循环队列**:数组实现队列时用取模,避免每次出队 O(n) 搬移。
- 均摊分析:两栈队列、动态数组扩容都是均摊 O(1)。

## 实践经验 / 踩坑

1. **括号匹配只数左右数量** —— 没考虑顺序 / 嵌套;必须用栈比对类型与顺序。
2. **单调栈方向记反** —— 求下一个更大 vs 上一个更大;栈里维护的是「还没找到答案的元素」。
3. **单调队列忘弹过期队首** —— 窗口滑过队首仍用它,结果错。
4. **两栈队列每次都倒** —— 出栈没空就倒,浪费;只在出栈空时倒。
5. **BFS 入队才判 visited** —— 应**入队即标记**,否则重复入队甚至死循环。
6. **递归爆栈** —— 深递归可用显式栈改迭代。
7. **数组队列搬移** —— 用循环队列(取模)避免每次出队 O(n) 搬移。

# 链表

## 概述
链表靠指针串联、内存不连续,O(1) 插删、O(n) 访问。高频:**反转**、**判环 / 找环入口**(快慢指针)、合并 / 相交、虚拟头节点(dummy)简化边界。核心是清晰操作指针的顺序与边界。

## 核心原理 / 关键点

### 1. 链表类型与特性

- **单链表**:每节点存 next;**双链表**:还有 prev(可双向遍历);**循环链表**:尾指向头。
- 内存不连续 → **O(1) 插入 / 删除**(改指针);但**O(n) 访问**(不能随机,只能遍历)。
- 频繁插删、大小不定 → 链表;需随机访问 → 数组。

### 2. 指针操作的核心:顺序与暂存

- 改指针前**先用临时变量保存**要被覆盖的 next,避免断链。
- 反转 `prev/cur/nxt`:先存 nxt → `cur.next=prev` → `prev=cur` → `cur=nxt`。
- 经典错:直接 `cur.next=prev` 把后面的链丢了。

### 3. 虚拟头节点 dummy

- 在头前加 dummy,统一处理「头可能被改 / 删」的边界,免去单独判头。
- 返回 `dummy.next`。链表题几乎都该先想 dummy。

### 4. 快慢指针

- **找中点**:快 2 步慢 1 步,快到尾时慢在中点。
- **判环**:快慢相遇则有环;**找环入口**:相遇后一指针回 head,两指针同速再相遇即入口。
- **倒数第 k**:快先走 k 步,再同速走到尾,慢即倒数第 k。

### 5. 反转链表(全反 / 区间 / k 个一组)

- 全反转:迭代(prev/cur)或递归。
- 区间反转 [m,n]:定位前后断点,局部反转再接回。
- k 个一组反转:分组反转,不足 k 个不反。

### 6. 合并 / 相交

- **合并两个有序链表**:双指针比较、dummy 串联。
- **合并 k 个**:小顶堆每次取最小节点,或分治两两合并。
- **相交 / 判交点**:双指针走对方链表(等长化)相遇即交点;或用集合记录。

### 7. 删除节点

- 普通删除:找前驱改 next。
- **只给被删节点**:把后继值复制过来再删后继(单向链表无法真删自己)。
- 删除倒数第 k:快慢指针定位前驱。

### 8. 递归思维与边界

- 链表是递归结构:「头 + 反转后的子链」,递归反转、回文判断(递归后序≈反向遍历)很自然。
- 代价:递归栈 O(n),大数据量改迭代。
- 边界:空链表 / 单节点必须先判,否则解引用 null。

## 实践经验 / 踩坑

1. **改指针顺序错断链** —— 没暂存 next 就覆盖;先存临时变量。
2. **没用 dummy** —— 头要改 / 删时一堆边界 if;统一用 dummy。
3. **判环忘找入口的两步** —— 只会判有没有环,不会定位入口。
4. **删除节点没找前驱** —— 单向链表删节点要知道前驱;或用复制值法。
5. **倒数第 k 越界** —— k > 链长没处理;快指针先走时判是否提前到尾。
6. **递归爆栈** —— 链很长时递归反转栈溢出;大数据改迭代。
7. **边界:空链表 / 单节点** —— 没判直接解引用 null;先判 head。

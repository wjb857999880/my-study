# 哈希表

## 概述
哈希表用哈希函数把 key 映射到桶,**平均 O(1) 查找 / 插入**,代价是无序与额外空间。冲突处理:拉链法、开放寻址。高频:两数之和、去重、计数、O(1) 判存在。注意最坏 O(n) 与扩容 rehash。

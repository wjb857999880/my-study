# 图 BFS 与 DFS

## 概述
图由顶点与边组成,用邻接表 / 邻接矩阵存储。**BFS**(队列)求最短步数 / 层序;**DFS**(递归或栈)求连通 / 环 / 路径。高频:岛屿数量、拓扑排序、最短路。关键是正确建图与 `visited` 去重。

## 核心原理 / 关键点

### 1. 图的表示

- **邻接表**:每点存其邻居链表 / 数组,适合**稀疏图**(省空间 O(V+E))。
- **邻接矩阵**:V×V 矩阵存边,适合**稠密图**、查边 O(1),但空间 O(V²)。
- 有向 / 无向、带权 / 无权;**正确建图**是解题第一步。

### 2. BFS:层序与最短步数

- 队列 + `visited`:从起点层层扩展。
- **无权图最短路径 / 最少步数**:BFS 第一次到达即最短。
- 层序:每处理一层步数 +1。
- **入队即标记 visited**,避免重复。

### 3. DFS:连通 / 环 / 路径

- 递归(或显式栈)深入,回溯探索。
- **连通分量**(如岛屿数量):遍历每点,未访问则 DFS/BFS 标记整块。
- 适合「是否连通 / 能否到达 / 所有路径」。

### 4. 岛屿与网格图

- 二维网格看作图,每格与上下左右相邻。
- 经典:**岛屿数量 / 最大岛屿 / 周长**:遍历 + DFS/BFS「淹没」访问过的格子。
- 原地标记(改网格值)省去 visited 数组。

### 5. 拓扑排序

- **DAG(有向无环图)**的拓扑序:所有边方向一致。
- BFS(Kahn):入度为 0 的点先入队,处理时邻居入度 -1,变 0 再入队。
- 应用:任务依赖、编译顺序、课程表;能拓扑排序 ⇔ 无环,顺带判环。

### 6. 最短路算法

- **无权图**:BFS。
- **非负权**:**Dijkstra**(优先队列,贪心取最近点)。
- **含负权**:**Bellman-Ford**(可判负环)。
- **多源最短路**:**Floyd**(动态规划 O(V³))。
- 选型看图的规模与边权。

### 7. visited 与去重

- **入队 / 入栈即标记 visited**,否则同点重复入队、甚至死循环。
- 网格题常用「访问过的格子置特殊值」原地标记。
- 记录路径时用 pre 数组回溯。

### 8. 建模与复杂度

- 第一步常是**把问题抽象成图**(格子 = 点、状态 = 点、转移 = 边),如单词接龙、状态搜索。
- BFS / DFS 都 O(V+E);Dijkstra O((V+E)logV)。
- 状态空间大时考虑双向 BFS / A* 剪枝。

## 实践经验 / 踩坑

1. **visited 标记时机错** —— 出队才标记 → 同点多次入队;入队即标记。
2. **建图方向 / 是否有向搞错** —— 无向当有向或反之;看清题意。
3. **网格越界** —— DFS/BFS 没判边界,数组越界。
4. **拓扑排序漏判环** —— 输出点数 < V 说明有环;要检查。
5. **BFS 当有权图最短路用** —— BFS 只适用无权 / 等权;有权用 Dijkstra。
6. **邻接矩阵用于稀疏图** —— 空间 O(V²) 浪费;稀疏用邻接表。
7. **DFS 递归爆栈** —— 图很大时递归 DFS 栈溢出;改 BFS 或显式栈。

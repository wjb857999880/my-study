# 二叉树

## 概述
二叉树的核心是**递归**:前 / 中 / 后 / 层序遍历。高频:最大深度、翻转、最近公共祖先、路径问题、BST 性质。多数树题 = 把问题拆成「当前根 + 左右子树」的递归结构,关键是想清递归函数的返回含义。

## 核心原理 / 关键点

### 1. 二叉树与递归

- 二叉树是**递归定义**:一棵树 = 根 + 左子树 + 右子树。
- 多数树题骨架:「**当前节点做什么 + 交给左右子树递归**」,关键是想清**递归函数返回值的含义**。
- 两种视角:**遍历**(用外部变量记答案)vs **分解问题**(函数返回子问题的解,如 `max(左, 右)+1`)。

### 2. 四种遍历

- **前序**(根左右)、**中序**(左根右)、**后序**(左右根):DFS 递归,区别在「处理根」的时机。
- **层序**:BFS + 队列逐层。
- 中序遍历 BST 得**升序序列**(BST 重要性质)。
- 遍历是所有树题的基础操作。

### 3. BFS 层序 vs DFS 深度

- **层序 BFS**:队列、按层处理,适合「层相关信息」「最短 / 最小深度」。
- **DFS(前 / 中 / 后)**:栈 / 递归,适合「路径」「深度」「子树信息汇总」。
- 选择:求最浅层 → BFS;求所有路径 / 深度 → DFS。

### 4. 经典递归题

- **最大深度**:`max(depth(left), depth(right)) + 1`。
- **翻转 / 对称**:递归处理左右子树。
- **直径**:最长路径 = 左深 + 右深;后序遍历时用全局变量更新。
- **平衡判断**:左右子树高度差 ≤ 1 且都平衡(后序,提前返回 -1 剪枝)。

### 5. 最近公共祖先 LCA

- 递归:在左右子树找 p、q;若分散在两侧 → 当前节点是 LCA;若都在一侧 → LCA 在那侧。
- 思想是「自底向上」汇聚。

### 6. 二叉搜索树 BST

- 性质:**左 < 根 < 右**,中序升序。
- 查找 / 插入 / 删除 O(h)(h 树高;平衡则 logn,退化链则 n)。
- 高频:验证 BST(中序判升序)、第 k 小(中序)、范围和。
- 删除节点:分无子 / 一子 / 两子(用前驱或后继替换)三情况。

### 7. 路径与子树问题

- 路径和:前缀和(根到节点)+ 回溯;或递归「以当前节点为起点」。
- 子树判断:递归「两树是否相同」+ 在每个节点调用。
- 递归返回值设计是关键(返回高度 / 是否 / 路径数等)。

### 8. 递归 vs 迭代 + 复杂度

- 递归最自然但栈空间 O(h);可改**显式栈**迭代(前 / 中 / 后序用栈模拟)。
- 时间大多 O(n)(每节点访问一次),空间 O(h)(栈)。
- 退化成链(斜树)时 h = n;平衡树 h = logn —— 这就是平衡树(AVL / 红黑)存在的理由。

## 实践经验 / 踩坑

1. **递归返回值含义没想清** —— 写出来不对;先明确「这个函数返回什么」。
2. **遍历 vs 分解问题混用** —— 用遍历视角写分解问题,或反之;选一种贯彻到底。
3. **BST 忘中序升序性质** —— 验证 / 第 k 小都能用中序简化。
4. **LCA 没考虑 p 是 q 祖先** —— 边界;先判存在性。
5. **需要汇总子树信息却用前序** —— 应在后序(先有左右结果才能算当前)。
6. **删除 BST 节点忘处理两子情况** —— 要用前驱 / 后继替换。
7. **树退化成链 → O(n)** —— 不平衡 BST 性能差;理解为什么要有平衡树。

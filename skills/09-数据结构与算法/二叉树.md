# 二叉树

## 概述
二叉树的核心是**递归**:前 / 中 / 后 / 层序遍历。高频:最大深度、翻转、最近公共祖先、路径问题、BST 性质。多数树题 = 把问题拆成「当前根 + 左右子树」的递归结构,关键是想清递归函数的返回含义。

# 排序与二分查找

## 概述
**快排**(分治,平均 O(nlogn))、**归并**(稳定,可求逆序对)、**堆排序**(TopK / 优先队列)。**二分查找**在有单调性的序列上 O(logn) 定位,核心是确立「不变量」与边界写法(左闭右开等),最易写错在循环条件与 mid。

## 核心原理 / 关键点

### 1. 排序算法概览

- 比较排序下界 O(nlogn)。常见:快排、归并、堆(都 O(nlogn));冒泡 / 选择 / 插入 O(n²)(小数据或近乎有序时插入快)。
- 关注:**时间、空间、稳定性**(相等元素是否保持原序)、是否原地。

### 2. 快速排序(分治)

- 选 pivot,partition 把小的放左、大的放右,递归两边。平均 O(nlogn)、原地、**不稳定**。
- 最坏 O(n²)(pivot 每次取到最值);**随机化 pivot** 或**三数取中**避免退化。
- 工程上常是混合排序(如 TimSort / 内省排序 introsort)。

### 3. 归并排序(分治 + 稳定)

- 分成两半分别排,再合并。O(nlogn)、**稳定**,但需 O(n) 额外空间。
- 副产品:**合并时数逆序对**、外部排序(大文件)。
- TimSort(归并 + 插入优化)是 Java / Python 默认排序。

### 4. 堆排序与 TopK

- 堆是完全二叉树,大顶堆根最大。建堆 O(n),排序 O(nlogn)、原地、不稳定。
- **TopK / 优先队列**:维护大小为 k 的堆,求前 k 大用小顶堆 O(nlogk)。
- 堆的应用:动态求最值、合并 k 个有序流。

### 5. 二分查找的前提与思想

- 前提:**有序(单调性)** + 随机访问。
- 思想:每次比较中间值,排除一半,O(logn)。
- 也可用于「**有单调性的答案空间**」二分(如「最小满足某条件的值」)。

### 6. 二分的边界写法(最易错)

- 关键:确立一个**不变量**(如「答案一定在 [left, right] 内」),循环条件、mid、更新都要维护它。
- 两种写法:左闭右闭 `[l,r]`(`while l<=r`),左闭右开 `[l,r)`(`while l<r`)。
- `mid = l + (r-l)/2` 防溢出(不用 `(l+r)/2`)。
- 找第一个 / 最后一个满足条件的值:用统一模板(左边界 / 右边界)。

### 7. 稳定性与选型

- 需稳定 → 归并 / TimSort(对象排序常需稳定)。
- 小数据 → 插入排序(常数小)。
- TopK → 堆或快速选择 O(n);全排序再取浪费。
- 面试一般要求手写快排 partition + 二分模板。

### 8. 常见变体与坑

- **二分答案**:把「求最值」转成「判定 mid 是否可行」二分。
- **旋转排序数组查找**:两段有序,判断 mid 落在哪段。
- **求平方根 / 第 k 小**:二分思想。
- 坑:死循环(mid 更新没缩范围)、越界、整数溢出。

## 实践经验 / 踩坑

1. **二分死循环** —— mid 更新没缩范围 / 循环条件错;确立不变量后照写。
2. **mid 溢出** —— `(l+r)/2` 大数溢出;用 `l+(r-l)/2`。
3. **快排退化 O(n²)** —— 固定取首元素为 pivot 遇有序输入退化;随机化 / 三数取中。
4. **稳定性误判** —— 以为快排稳定;对象排序要稳定选归并 / TimSort。
5. **TopK 用全排序** —— O(nlogn) 浪费;用大小 k 的堆或快速选择 O(n)。
6. **二分边界返回值错** —— 找左 / 右边界写法不同;用对应模板。
7. **无序数组用二分** —— 二分要单调性;先排序或确认单调。

# 动态规划

## 概述
DP 把问题拆成**重叠子问题 + 状态转移**,用记忆化 / 递推避免重复计算。四要素:**状态定义、转移方程、初始值、遍历顺序**。高频:背包、最长上升 / 公共子序列、路径计数、区间 DP、状态压缩。

## 核心原理 / 关键点

### 1. DP 的本质

- 适用:**最优子结构 + 重叠子问题**。
- 最优子结构:大问题最优解由子问题最优解构成;重叠子问题:子问题被反复计算 → DP 用表存下避免重复。
- 与分治区别:分治子问题独立不重叠,DP 子问题重叠。

### 2. 四要素

- **状态定义**:`dp[i]` / `dp[i][j]` 代表什么(最关键,决定难易)。
- **转移方程**:从哪些更小子问题推出当前(如 `dp[i]=max(dp[i-1], dp[i-2]+nums[i])`)。
- **初始值(边界)**:`dp[0]` 等基础情况。
- **遍历顺序**:保证算当前时依赖的子问题已算好。

### 3. 两种实现:记忆化 vs 递推

- **自顶向下 + 记忆化**(递归 + 缓存):思路自然,适合状态难枚举。
- **自底向上 + 递推**(循环填表):无递归栈、常数小,工程常用。
- 两者等价;先想清状态转移,再选实现。

### 4. 经典线性 DP

- **爬楼梯 / 斐波那契**:`dp[i]=dp[i-1]+dp[i-2]`。
- **打家劫舍**:选不选当前 → max(不选, 选 + dp[i-2])。
- **最长上升子序列 LIS**、**最长公共子序列 LCS**。
- **最大子数组和**(Kadane):`dp[i]=max(nums[i], dp[i-1]+nums[i])`。

### 5. 背包问题

- **0-1 背包**:每物品选 / 不选;**完全背包**:物品无限;**多重背包**:物品数量有限。
- 状态 `dp[i][容量]`,转移看选不选第 i 个。
- 空间优化:二维压成一维(**0-1 背包容量倒序遍历**)。

### 6. 区间 DP 与状态压缩

- **区间 DP**:`dp[i][j]` 表示区间 [i,j] 的解,按区间长度递增枚举(戳气球、矩阵链)。
- **状态压缩(bitmask DP)**:状态用二进制位表示集合(TSP、小规模集合划分)。

### 7. 路径与计数 DP

- **不同路径**:网格左上到右下,`dp[i][j]=dp[i-1][j]+dp[i][j-1]`。
- 计数类 DP 转移多为「相加」而非「取最值」。

### 8. 空间优化与适用判定

- **滚动数组**:只依赖前一行 / 前一项时,压到 O(1) 或 O(n)。
- 初始值与遍历方向是主要错点(背包压维时容量必须倒序)。
- 判定能否 DP:有最优子结构 + **无后效性**(当前状态只由之前决定,之后的决策不影响之前)。

## 实践经验 / 踩坑

1. **状态定义不当** —— 转移写不出;换角度定义 `dp`(如加一维表示状态)。
2. **遍历顺序错** —— 依赖没就绪;背包压维要倒序容量。
3. **初始值 / 边界漏** —— `dp[0]` 或空串 / 空集合情况没设对。
4. **空间没优化** —— 二维能压一维;但压维后遍历方向要相应改。
5. **误把有后效性的当 DP** —— 后续决策影响前面状态时不能简单 DP。
6. **记忆化没缓存** —— 递归不存结果 → 退化成指数级。
7. **混淆 DP 与贪心** —— 贪心要可证明局部最优 = 全局最优;DP 适合子问题组合。

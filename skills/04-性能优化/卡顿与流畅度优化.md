# 卡顿与流畅度优化

## 概述
目标是稳定 60/120fps、消除掉帧(jank)。原理:每帧须在 16.6ms 内完成 measure/layout/draw + 主线程消息处理,超时即掉帧。排查:**Perfetto / Systrace** 看主线程每帧耗时、`Choreographer` / `FrameMetrics` 测帧时长、BlockCanary 监测卡顿堆栈。手段:主线程去重活(异步 / 缓存 / 预计算)、减少过度绘制与层级、避免主线程 IO 与同步解码大图。

## 核心原理 / 关键点

### 1. 什么是卡顿 / 帧率标准

屏幕每秒刷新 N 次,**掉帧(jank)** = 一帧没在刷新周期内渲染完成,导致画面不连贯(卡顿)。标准:多数设备 **60fps**(每帧 ≈ 16.6ms 预算),高刷屏 **90 / 120fps**(预算更短,≈ 8.3 / 4.2ms)。优化目标:稳定不掉帧。

### 2. 渲染原理:VSYNC + Choreographer + 帧预算

- **VSYNC(垂直同步)**:硬件每帧发一次信号,触发系统开始这一帧的 measure / layout / draw。
- **Choreographer**:接收 VSYNC,按帧调度主线程的输入 / 动画 / 绘制任务。
- **帧预算**:一个 VSYNC 周期内(60fps ≈ 16.6ms)要完成「主线程所有工作 + 渲染」,超时就掉这一帧。

### 3. 掉帧根因

主线程在帧周期内做了太多 / 太重的事:① **measure / layout / draw 重**(层级深、过度绘制、复杂自定义 View);② **主线程 IO / 同步解码大图 / JSON 解析**;③ **GC 停顿**(频繁分配触发);④ 主线程消息队列被其他消息占用。本质是「主线程一帧干不完」。

### 4. 检测工具

- **Perfetto / Systrace**:抓系统 + 应用 trace,看主线程每帧各段耗时、是否掉帧、掉帧原因(GC / IO / 布局)。
- **FrameMetrics**(`Window.OnFrameMetricsAvailableListener`):代码里测每帧 measure / layout / draw / total 耗时。
- **BlockCanary / Looper 监控**:在主线程 dispatch 前后埋点,超阈值抓卡顿堆栈。
- GPU 呈现模式分析(开发者选项):看每帧柱状图是否超绿线。

### 5. UI 层优化

- **减层级 / 扁平化**:`<merge>`、ConstraintLayout 替代多层嵌套、`<include>` 复用。
- **ViewStub 延迟 inflate**:非首屏用 ViewStub,需要时才 inflate。
- **减少过度绘制**:移除多余背景、`canvas.clipRect` 限定绘制区。
- **列表优化**:RecyclerView 复用 + DiffUtil 精准更新 + `onBindViewHolder` 别做重活(见 RecyclerView 四级缓存)。

### 6. 主线程去重活

- 异步:耗时操作(网络 / IO / 解码 / 计算)挪协程 IO / 子线程。
- 缓存 / 预计算:能缓存的别每帧算。
- 避免主线程同步 IO、大 JSON 解析、同步图片解码。

### 7. 动画与渲染优化

- 用**属性动画** / `ViewPropertyAnimator`(硬件层加速)而非每帧 `requestLayout`。
- 复杂动画用 `LAYER_TYPE_HARDWARE`(硬件层)离屏缓存。
- 避免**每帧触发 layout**:只改 translation / alpha / scale 不触发布局;改 margin / width 会 `requestLayout`。

### 8. 持续监控与防回归

- 定**帧率基线**(目标 fps、掉帧率),CI / 灰度用 Macrobenchmark 测流畅度。
- 线上 APM 采集卡顿堆栈与帧率,关联版本防回归。
- 冷启动 / 滑动 / 动画等关键路径重点守护。

## 实践经验 / 踩坑

1. **onBindViewHolder 做重活** —— 列表滚动卡;重活异步 / 缓存,diff 精准更新。
2. **布局层级太深** —— measure / layout 每帧耗时;扁平化 + ConstraintLayout。
3. **主线程同步解码大图 / IO** —— 一帧干不完;挪子线程 + 采样。
4. **过度绘制严重** —— 多层背景叠加;移除无用背景 + clipRect。
5. **动画每帧 requestLayout** —— 触发重测量;改用 translation / alpha 等不布局的属性。
6. **频繁分配触发 GC** —— onDraw / 循环里 new 对象;复用对象。
7. **优化不量化** —— 凭感觉;用 Perfetto / Macrobenchmark 定基线 + 监控防回归。

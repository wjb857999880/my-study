# 内存优化

## 概述
目标是降内存峰值、防 OOM、查泄漏。工具:**Profiler** 看内存曲线与对象、**LeakCanary** 自动检测泄漏、**MAT / Profiler hprof** 分析引用链。常见泄漏:静态 / 单例持 Activity、匿名内部类与 Handler 持 Context、未注销监听、WebView。手段:弱引用、生命周期解绑、大图采样(inSampleSize)、`onTrimMemory` 主动释放、对象池复用。

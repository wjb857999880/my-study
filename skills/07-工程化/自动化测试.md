# 自动化测试

## 概述
高级岗要求能建立测试体系:**单元测试**(JUnit + Mockito / Robolectric,测纯逻辑)、**Instrumentation 测试**(跑在设备上,AndroidX Test)、**UI 测试**(Espresso 测 View 体系、Compose UI test 测 Compose)。分层:可测性从架构做起(依赖注入、Repository 抽象)。目标不是 100% 覆盖,而是关键业务逻辑 + 回归保护。配合 CI 在每次提交跑测试,把缺陷挡在合入前。
